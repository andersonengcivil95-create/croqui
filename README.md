# Croqui de Medidas

App instalável (PWA) para desenhar croqui de casa com medidas: paredes que endireitam sozinhas, cotas, portas, janelas, terreno, quadro de áreas, PDF em escala, DXF para AutoCAD e arquivo para o Revit. Funciona offline depois de aberto uma vez.

Abra o endereço do GitHub Pages no Chrome do tablet ou do celular e toque em **Instalar app**.
